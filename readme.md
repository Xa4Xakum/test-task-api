# Запуск проекта
- в директории с проектом docker build -t <ваше название> .
- следом docker run -p 8000:8000 <ваше название>

### Если вдруг вы удалили .db файл
Просто перезапустите проект, таблицы создадутся автоматически, это оставлено намеренно для упрощения запуска

### Как пользоваться
После запуска API будет доступно по адресу http://localhost:8000, документация лежит на пути /docs, там описаны все методы взаимодействия
База данных первично заполнена тестовыми данными, при желании можно удалить файл .db и заново запустить проект - база должна автоматически сгенерироваться без данных, но с нужными таблицами
